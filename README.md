# 🛍️ Product Review Analyzer

## 📌 Project Description

**Product Review Analyzer** is a web-based application that analyzes customer reviews and identifies whether the review is **Positive, Negative, or Neutral**. It helps users quickly understand customer opinions about a product.

## 🎯 Features

* 📝 Enter a product review
* 🔍 Analyze the review
* 😊 Detect Positive reviews
* 😐 Detect Neutral reviews
* 😞 Detect Negative reviews
* 📊 Display the analysis result
* 💻 Simple and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive design
* **JavaScript** – Review analysis and interactive functionality

## 🚀 How to Run the Project

### Step 1: Download or Clone the Project

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project

Open the project folder in **VS Code**.

### Step 3: Run the Application

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.

### Step 4: Enter a Review

Example:

```text
This product is very good and the quality is excellent.
```

Click the **Analyze Review** button.

### Step 5: View the Result

The application displays the sentiment of the review, such as:

```text
Sentiment: Positive
```
